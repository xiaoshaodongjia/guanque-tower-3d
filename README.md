# 鹳雀凌云 · 鹳雀楼数字化漫游

沿黄河入境，读建筑、听唐诗，收藏属于自己的山河一瞬。

**在线体验：<https://xiaoshaodongjia.github.io/guanque-tower-3d/>**

## 六个体验入口

- **四境**：一键连续导览，镜头与日暮光照、音乐、讲述和诗句联动。支持暂停、继续、上一境、下一境；拖拽或缩放可接管，再点击继续平滑接回。
- **游园**：俯瞰景区，依次查看前广场、门楼与廊房、鹳影湖、圆形广场、大地诗景和高台前庭。总览根据电脑或手机的可见画面自动取景，缩放距离设有上下限。可逐站切换，也可直接进入楼内，接续楼层故事。
- **观筑**：探索斗拱、筒瓦、正脊与鸱吻、立柱、高台；也可打开九层内部结构，半剖外壳、查看骨架、逐层选择或展开九层。进入「入楼漫游 · 楼层故事」，可在楼内行走、沿折返楼梯上下层；到达楼身六层分别自动展开故事，台基三层提供主动打开的结构说明。
- **诗境**：点击《登鹳雀楼》的四句诗，分别欣赏落日、黄河、远望和登高镜头；也可连续欣赏全诗。
- **古今**：通过五个时间节点了解古楼与现代复建，附景区介绍来源。
- **留念**：收集望河、观楼、识筑、临高、赏暮、入诗六枚印章，生成包含当前视角、诗句、日期和印章的 PNG 明信片。

## 操作与声音

初次游览会出现简短引导，可选择「跟随导览」或「自由看楼」；已有探索记录的访客直接进入。画面下方的「游览帮助」可随时重开引导，「回到楼前」可从景区、构件或楼内回到完整楼阁。

手机上可以「收起面板」，保留体验标签与导览控制，让更多画面留给建筑；切换体验标签时自动展开。楼体取景按实际构件和屏幕可见区域计算，兼顾台基、石阶及展开楼层，横竖屏切换也会重新取景。

「游览帮助」提供「减少镜头运动」：初始跟随设备偏好，手动选择后记住设置，也可恢复跟随设备。开启时，四境采用固定视角，诗境和构件直接切换视角，上下楼直接到达；水面和结构展开停止连续动画。手动转动、缩放和楼内行走仍可使用。打开帮助或图文阅读时暂停导览与声音；导览可手动继续。

加载界面和游览帮助均可进入「图文游览」。建筑介绍、唐诗与六层故事直接包含在页面内，使用浏览器原生展开阅读，不依赖三维初始化成功或 JavaScript 执行；内容由同一份楼层故事资料生成。

外观模式下，电脑拖拽旋转、滚轮缩放；手机单指转动、双指缩放。

入楼后拖拽环视，用 W/A/S/D、方向键或屏幕方向按钮行走。E /「上楼」和 Q /「下楼」沿示意楼梯前往邻层；楼层菜单可直接前往指定楼层。故事正文可滚动阅读，下方固定显示「读完了，继续漫游」；阅读时不会因方向键误走动。「重读本层故事」可再次打开。Esc 优先收起故事，故事关闭后再按 Esc，或点击「返回结构剖视」，离开第一人称漫游。

楼内提供「开阔视野 / 自然视野」切换，镜头根据控制面板以外的可见区域取景，并记住选择。手机进入漫游时自动收起面板，仍可环视、行走、上下楼与返回剖视；展开后可选楼层、重读故事和查看资料依据。

楼身一至六层的数字故事依次为：河畔起高楼、二十字里的山河、楼隐诗传、重建再续登临、唐风与今工、更上一层楼。主题根据公开资料编排，不对应真实展厅分配，也不表示每一处均向游客开放。台基三层不自动弹故事、不计入六个故事足迹，可主动查看建筑结构说明。楼层故事当前以文字呈现。

「观筑」提供「楼前近景」「檐下细看」，可以直接观察灰石铺地、柱身漆面、门环与檐下彩画。「入楼漫游」的首层按实拍调整为通高大厅，上方连通二层环形回廊，配有朱红柱、浅色回纹栏板、青绿蓝色梁枋、方格彩绘顶棚和灰色方砖。入口视点位于第一排柱子以内，中央保持开敞；在二层可沿栏杆俯瞰首层。

首层西侧的《中都蒲坂繁盛图》增加了立体微缩城市场景：灰瓦院落、分层街市、城门、人物、蒲津渡浮桥、铁牛意象与河岸古楼。《筑楼戍边》《旗亭画壁》按现场照片中可辨认的人物、白马、旌旗、酒案和歌乐元素作数字重绘。图像与造型均为示意，非原作照片或精确复制；入口的低导览牌与座椅属于数字设施。展陈避开主要通道，两侧楼梯可达，二层洞口设有行走碰撞边界。返回结构剖视时隐藏展陈，恢复楼板的依据颜色。

在首层或二层回廊，点击画面中的展项或“首层三展”标题，可阅读对应故事、画面观察提示和两篇来源文章；支持前后切换、键盘关闭与手机阅读。拖拽环视不会误开讲解，墙柱会遮挡点选。展项阅读不额外计入六层故事足迹。图文游览也包含同一份首层展项内容，不依赖三维加载。《旗亭画壁》明确标为文学典故，不将故事场所设定在鹳雀楼内。

默认先进入流畅画质；点击右上角「精细画质」可载入更细致的瓦片、斗拱与材质。下载时可继续游览，切换会保留当前镜头、分层状态和探索进度。再次点击可切回流畅画质。

初次点击「启程」或「开启声音」后播放声景。右上角「声音设置」可选择 **Jannik《浮光（The History）》** 或 **原配乐 · 山河五音**，并记住选择；默认选《浮光》。首次打开或刷新页面不会自动出声，手动关闭声音后会记住静音偏好。

《浮光》通过[网易云公开音频外链](https://music.163.com/song/media/outer/url?id=1394601255.mp3)在线播放，开启声音后才联网载入。声音设置中的「《浮光》音量」默认 **20%**，可单独调整并记住选择，朗诵时自动降低；也可播放、暂停和拖动歌曲进度。切换回原配乐、关闭声音或页面进入后台时会暂停，返回后从原进度继续。载入失败时可重试或前往网易云歌曲页。部分浏览器（如 iOS 上的部分版本）由系统控制媒体音量；如果网页音量设置未生效，界面会提示使用设备音量键。

原配乐的全部音频保留在 `assets/audio/`，是本项目原创合成的五声音景，会随白日、黄昏变换，并在朗诵时自动降低。可单独调整原配乐、风与水的音量，关闭或开启朗诵；两种背景配乐不会同时播放。朗诵与简短讲解采用普通话云扬合成男声。完整文字与音频说明见 [音频说明](assets/audio/credits.json)。

## 模型与内容

建筑依据实景照片、公开施工方案与工程介绍制作，黄河、远山和天空由程序生成。该作品用于建筑结构与文化内容展示，不是测绘级复原，也不代表官方景区导览。

景区周边以用户提供的实景航拍和卫星截图为依据，表现入口门区、双翼状鹳影湖与中轴桥、圆形广场、几何绿地、两侧林带、入口侧停车区，以及卫星图中主楼左侧的《登鹳雀楼》大地诗景。概念总平面只存档，没有将其中未经实景确认的布局加入模型。截图未提供可用比例尺，周边尺寸、园路细节、树种树位和附属建筑细部仍为示意；园内景观湖与远景黄河分别表现。范围和出处见[周边模型说明](assets/surroundings-notes.json)。

周边是独立 GLB，约 4.14 MB，压缩后约 1.63 MB，含 106,164 个三角面与 46 个绘制网格。模型在主体载入后异步加载；「游园」可显示或隐藏周边，加载失败时可重试。桌面 HTML 同样内嵌周边模型。

外观模型总高校准为 73.9 米，楼身首层地坪为 16.5 米，第四层起点为 38.13 米。外观中层、上层对应楼身第四、第六层。补充了柱头卷杀、上部柱轴线内收、斗拱承托与出跳、彩画白线和平棋天花；首层楼身按资料不设栌斗。

外观按正面实拍与侧面航拍收窄顶层正脊，调整凹曲屋坡、鸱吻、中央宝顶和四面抱厦；灰瓦边缘表现灰绿琉璃剪边，柱身与门窗采用较深褐漆色。首层横匾按实物照片右起读为“文萃李唐”，顶层竖匾为“鹳雀楼”；正面两侧补入“凌空白日三千丈 / 拔地黄河第一楼”。字形采用行楷排版，不是原题字手迹的逐笔复制。

台基按航拍补齐正面两段宽阶、中间横向翼台、左右转折侧梯，以及首层十字台座四向入口短阶。各梯段采用连续封闭实体，梯口石栏留出通道；上下平台共用连接边界，避免重叠踏面。台基平面、侧梯位置与具体踏步数仍是照片和人体尺度拟合参数，不作为竣工尺寸。

外观照片依据：[中国社区发展网正面实拍](http://cdcn.org.cn/article/28081)（2024-04-09）、[新华网／山西日报斜正面照片](http://sx.news.cn/20240719/78c1f36782774b1aa7f55b3e0f8b6f5e/c.html)（2024-07-19，永济融媒体中心供图）、[申威隆《永济市：航拍鹳雀楼景区》](https://www.sohu.com/a/920450889_428863)（2025-08-03）、[《观览鹳雀楼（山西行之三）》牌匾与楹联近照](https://www.meipian.cn/2fdm0o2y)（2019-10-01）。横匾以照片文字为准，未采用游记正文倒置的字序。参考图片用于轮廓和构件对照，没有作为网站贴图发布。

流畅模型保留 353,640 个三角面，约 9.57 MB，gzip 后约 3.49 MB；精细模型保留 654,248 个三角面，约 22.57 MB，gzip 后约 9.12 MB。两者均按相同的外观层次、构件类型和材质分为 84 个绘制网格，支持完整互动。石材、漆面和瓦材使用程序纹理、法线与粗糙度贴图；铺石只替换原有表面材质，不叠加同标高楼板。流畅版降低曲面细分、细小倒角和贴图分辨率，保留建筑布局与构件。

首页提前请求流畅模型，精细模型只在主动切换画质时下载。内部结构模型单独按需加载，约 3.39 MB，gzip 后约 0.42 MB，不增加首次进入的模型下载量。模型和每段音频各自使用内容哈希作为缓存版本。大厅展陈在首次进入首层或二层时由网页创建，使用内部程序材质、本地绘制的图文和彩绘纹理，不请求外部展板图片；静态细部按材质合并。声景首次开启时按需加载；独立 HTML 内嵌精细外观、内部结构与声音，包含同样的展陈代码。实际载入时间取决于网络与设备。

内部模型按台基三层、楼身六层建立楼板、内柱、框架梁、两侧剪力墙、楼梯及电梯井示意。楼身按资料中的 20 根内柱表达，12 根结合剪力墙，8 根独立。台基方柱的数量与位置属于示意。

**内部结构的范围：**台基一层、楼身一层、四层和五层有标高依据，以青绿楼板表示；其余五层采用推定标高，以赭黄色表示。全部水平轴线、楼板轮廓、墙厚、交通区的绝对位置、梯段与井道尺寸均待完整 CAD 核对。没有据此虚构当前展陈、房间用途或真实室内游览路线。

**大厅实景参考的范围：**实拍与施工正文中“二层回廊和一层洞口”的描述共同支持首层与二层相通。模型在二层楼板开洞，保留首层地面与上方天花。洞口的 10 × 12.6 米是模型拟合参数，回廊宽度、局部层高、柱位和彩绘细节仍为推定或简化；网上历史照片不能证明当前运营陈设完全相同。本轮集中精修首层与二层回廊，其余楼层继续使用结构示意和数字故事。

首层展陈主题与图像参考：[中国社区发展网《中华名楼——山西永济鹳雀楼》](http://cdcn.org.cn/article/28081)（2024-04-09）、[山西省政协转载《山西日报》〈鹳雀楼怀古〉](http://www.shanxizx.gov.cn/sjzc/sjsh/art/2022/art_d1c0f4e25ea5475fa8c26607a1795961.html)（2022-03-11）。这两篇历史图文可支持主题与构图，不据此确认当前展厅陈设完全一致。

照片参考：[首层大厅与展项游记](https://zhuanlan.zhihu.com/p/193093280)、[从回廊俯视大厅的实拍](https://www.nipic.com/show/33713653.html)、[回廊与彩绘摄影组](https://dp.pconline.com.cn/photo/list_4868240.html)。参考图片仅用于空间关系与构件色彩对照，没有作为网站纹理发布。

依据见[工程施工资料](https://www.gc5.com/jzgc/jzsg/10190840.html)、[公开施工方案正文](http://shigongdaquan.max.book118.com/01.公共设施施工组织设计/某楼复建工程施工组织设计方案.htm)、[景区介绍](http://sxgql.com/?about/)。逐层依据与推定记录见[内部模型说明](assets/interior-notes.json)，外观参数见[外观模型说明](assets/model-notes.json)。

探索进度、六层故事足迹和声音偏好保存在当前浏览器；不上传个人游览记录，无需账号和后台。

## 文件与维护

- `index.html`：界面与导览入口。
- `assets/experience-v2.css`、`assets/experience-v2.js`：样式、场景与交互。
- `assets/guanque-exploration.glb`：带楼层和构件分组的互动模型。
- `assets/guanque-fast.glb`：用于首次进入的流畅模型，分组与精细版一致。
- `assets/guanque-interior.glb`：九层内部结构示意，打开内部结构时加载。
- `assets/guanque-surroundings.glb`：根据实景与卫星截图制作的景区周边参考模型。
- `assets/surroundings-notes.json`：周边依据、示意范围和七个导览视角。
- `assets/interior-notes.json`：逐层标高、来源与推定范围。
- `assets/floor-stories.json`：楼身六层的故事与台基三层的结构说明，含资料来源。
- `assets/hall-exhibits.json`：首层三组展项的原创讲解、观察提示与图文来源。
- `assets/audio/`：保留的原创配乐、环境声、朗诵与讲解；《浮光》使用网易云音频外链，不在此目录中。
- `assets/vendor/`：Three.js 0.170.0 及必要模块。
- `tools/export-standalone.py`：从当前发布文件生成独立 HTML。

纯静态网站，无需构建工具或后端。可在仓库目录运行 `python3 -m http.server 8000`，然后访问 <http://localhost:8000/>。

生成可直接打开的独立 HTML（内嵌模型、音频和页面代码，Three.js 通过 CDN 引入）：

```sh
python3 tools/export-standalone.py
```

默认输出 `dist/guanque-tower.html`。线上版的页面、模型、原配乐、环境声、朗诵和 Three.js 由本站提供，运行时无需外部 CDN；选择《浮光》时会连接网易云。桌面 HTML 内嵌原有 17 段音频和模型，《浮光》同样需要联网播放。

GitHub Pages 使用 `main` 分支的 `/ (root)` 目录；推送更新后自动部署。`preview/` 为版本预览入口。
