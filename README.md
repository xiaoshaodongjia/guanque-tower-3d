# 鹳雀凌云 · 鹳雀楼数字化漫游

沿黄河入境，读建筑、听唐诗，收藏属于自己的山河一瞬。

**在线体验：<https://xiaoshaodongjia.github.io/guanque-tower-3d/>**

## 六个体验入口

- **四境**：一键连续导览，镜头与日暮光照、音乐、讲述和诗句联动。支持暂停、继续、上一境、下一境；拖拽或缩放可接管，再点击继续平滑接回。
- **游园**：俯瞰景区，依次查看前广场、门楼与廊房、鹳影湖、圆形广场、大地诗景和高台前庭。总览根据电脑或手机的可见画面自动取景，缩放距离设有上下限。可逐站切换，也可直接进入楼内，接续楼层故事。
- **观筑**：探索斗拱、筒瓦、正脊与鸱吻、立柱、高台；也可打开九层内部结构，半剖外壳、查看骨架、逐层选择或展开九层。进入「入楼漫游 · 楼层故事」，可在楼内行走、沿折返楼梯上下层；到达楼身六层分别自动展开故事，台基三层提供主动打开的结构说明。
- **诗境**：点击《登鹳雀楼》的四句诗，分别欣赏落日、黄河、远望和登高镜头；也可连续欣赏全诗。
- **古今**：通过五个时间节点了解古楼与现代复建，附景区介绍来源。
- **留念**：收集望河、观楼、识筑、临高、赏暮、入诗六枚印章，生成包含当前视角、诗句、日期和印章的 PNG 明信片。

## 操作与声音

外观模式下，电脑拖拽旋转、滚轮缩放；手机单指转动、双指缩放。

入楼后拖拽环视，用 W/A/S/D、方向键或屏幕方向按钮行走。E /「上楼」和 Q /「下楼」沿示意楼梯前往邻层；楼层菜单可直接前往指定楼层。故事收起后可继续走动，「重读本层故事」可再次打开；Esc 或「返回结构剖视」离开第一人称漫游。

楼身一至六层的数字故事依次为：河畔起高楼、二十字里的山河、楼隐诗传、重建再续登临、唐风与今工、更上一层楼。主题根据公开资料编排，不对应真实展厅分配，也不表示每一处均向游客开放。台基三层不自动弹故事、不计入六个故事足迹，可主动查看建筑结构说明。楼层故事当前以文字呈现。

默认先进入流畅画质；点击右上角「精细画质」可载入更细致的瓦片、斗拱与材质。下载时可继续游览，切换会保留当前镜头、分层状态和探索进度。再次点击可切回流畅画质。

初次点击「启程」或「开启声音」后播放声景。声音设置可分别调整配乐、风与水的音量，关闭或开启朗诵。手动关闭声音后会记住选择；朗诵时配乐自动降低。页面进入后台时暂停声音和导览推进。

配乐为本项目原创合成的五声音景，朗诵与简短讲解采用普通话云扬合成男声。完整文字与音频说明见 [音频说明](assets/audio/credits.json)。

## 模型与内容

建筑依据实景照片、公开施工方案与工程介绍制作，黄河、远山和天空由程序生成。该作品用于建筑结构与文化内容展示，不是测绘级复原，也不代表官方景区导览。

景区周边以用户提供的实景航拍和卫星截图为依据，表现入口门区、双翼状鹳影湖与中轴桥、圆形广场、几何绿地、两侧林带、入口侧停车区，以及卫星图中主楼左侧的《登鹳雀楼》大地诗景。概念总平面只存档，没有将其中未经实景确认的布局加入模型。截图未提供可用比例尺，周边尺寸、园路细节、树种树位和附属建筑细部仍为示意；园内景观湖与远景黄河分别表现。范围和出处见[周边模型说明](assets/surroundings-notes.json)。

周边是独立 GLB，约 4.14 MB，压缩后约 1.63 MB，含 106,164 个三角面与 46 个绘制网格。模型在主体载入后异步加载；「游园」可显示或隐藏周边，加载失败时可重试。桌面 HTML 同样内嵌周边模型。

外观模型总高校准为 73.9 米，楼身首层地坪为 16.5 米，第四层起点为 38.13 米。外观中层、上层对应楼身第四、第六层。补充了柱头卷杀、上部柱轴线内收、斗拱承托与出跳、彩画白线和平棋天花；首层楼身按资料不设栌斗。

流畅模型保留 324,014 个三角面，约 8.24 MB，gzip 后约 2.87 MB；精细模型保留 600,150 个三角面，约 20.22 MB，gzip 后约 7.78 MB。两者均按相同的外观层次、构件类型和材质分为 71 个绘制网格，支持完整互动。流畅版降低曲面细分、细小倒角和贴图分辨率，保留建筑布局与构件。

首页提前请求流畅模型，精细模型只在主动切换画质时下载。内部结构模型单独按需加载，约 3.00 MB，gzip 后约 0.38 MB，不增加首次进入的模型下载量。模型和每段音频各自使用内容哈希作为缓存版本。声景首次开启时按需加载；独立 HTML 内嵌精细外观、内部结构与声音。实际载入时间取决于网络与设备。

内部模型按台基三层、楼身六层建立楼板、内柱、框架梁、两侧剪力墙、楼梯及电梯井示意。楼身按资料中的 20 根内柱表达，12 根结合剪力墙，8 根独立。台基方柱的数量与位置属于示意。

**内部结构的范围：**台基一层、楼身一层、四层和五层有标高依据，以青绿楼板表示；其余五层采用推定标高，以赭黄色表示。全部水平轴线、楼板轮廓、墙厚、交通区的绝对位置、梯段与井道尺寸均待完整 CAD 核对。没有据此虚构当前展陈、房间用途或真实室内游览路线。

依据见[工程施工资料](https://www.gc5.com/jzgc/jzsg/10190840.html)、[公开施工方案正文](http://shigongdaquan.max.book118.com/01.公共设施施工组织设计/某楼复建工程施工组织设计方案.htm)、[景区介绍](http://sxgql.com/?about/)。逐层依据与推定记录见[内部模型说明](assets/interior-notes.json)，外观参数见[外观模型说明](assets/model-notes.json)。

探索进度、六层故事足迹和声音偏好保存在当前浏览器；不上传个人游览记录，无需账号和后台。

## 文件与维护

- `index.html`：界面与导览入口。
- `assets/experience-v2.css`、`assets/experience-v2.js`：样式、场景与交互。
- `assets/guanque-exploration.glb`：带楼层和构件分组的互动模型。
- `assets/guanque-fast.glb`：用于首次进入的流畅模型，分组与精细版一致。
- `assets/guanque-interior.glb`：九层内部结构示意，打开内部结构时加载。
- `assets/guanque-surroundings.glb`：根据实景与卫星截图制作的景区周边参考模型。
- `assets/surroundings-notes.json`：周边依据、示意范围和七个导览视角。
- `assets/interior-notes.json`：逐层标高、来源与推定范围。
- `assets/floor-stories.json`：楼身六层的故事与台基三层的结构说明，含资料来源。
- `assets/audio/`：配乐、环境声、朗诵与讲解。
- `assets/vendor/`：Three.js 0.170.0 及必要模块。
- `tools/export-standalone.py`：从当前发布文件生成独立 HTML。

纯静态网站，无需构建工具或后端。可在仓库目录运行 `python3 -m http.server 8000`，然后访问 <http://localhost:8000/>。

生成可直接打开的独立 HTML（内嵌模型、音频和页面代码，Three.js 通过 CDN 引入）：

```sh
python3 tools/export-standalone.py
```

默认输出 `dist/guanque-tower.html`。线上版的页面、模型、声音和 Three.js 全部由本站提供，运行时无需外部 CDN。

GitHub Pages 使用 `main` 分支的 `/ (root)` 目录；推送更新后自动部署。`preview/` 为版本预览入口。
