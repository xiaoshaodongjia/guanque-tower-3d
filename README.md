# 鹳雀凌云 · 鹳雀楼数字化漫游

沿黄河入境，读建筑、听唐诗，收藏属于自己的山河一瞬。

**在线体验：<https://xiaoshaodongjia.github.io/guanque-tower-3d/>**

## 五个体验入口

- **四境**：一键连续导览，镜头与日暮光照、音乐、讲述和诗句联动。支持暂停、继续、上一境、下一境；拖拽或缩放可接管，再点击继续平滑接回。
- **观筑**：探索斗拱、筒瓦、正脊与鸱吻、立柱、高台。点击标记或对应构件进入近景，阅读或收听讲解；可展开楼阁，按外观层次单独观察。
- **诗境**：点击《登鹳雀楼》的四句诗，分别欣赏落日、黄河、远望和登高镜头；也可连续欣赏全诗。
- **古今**：通过五个时间节点了解古楼与现代复建，附景区介绍来源。
- **留念**：收集望河、观楼、识筑、临高、赏暮、入诗六枚印章，生成包含当前视角、诗句、日期和印章的 PNG 明信片。

## 操作与声音

电脑拖拽旋转、滚轮缩放；手机单指转动、双指缩放。

初次点击「启程」或「开启声音」后播放声景。声音设置可分别调整配乐、风与水的音量，关闭或开启朗诵。手动关闭声音后会记住选择；朗诵时配乐自动降低。页面进入后台时暂停声音和导览推进。

配乐为本项目原创合成的五声音景，朗诵与简短讲解采用普通话云扬合成男声。完整文字与音频说明见 [音频说明](assets/audio/credits.json)。

## 模型与内容

建筑依据参考照片制作，黄河、远山和天空由程序生成。该作品用于外观与文化内容展示，不是测绘级复原，也不代表官方景区导览。

互动模型保留 508,070 个三角面，按外观层次、构件类型和材质合并为 69 个绘制网格，约 17 MB。材质贴图内嵌于 GLB；声景首次开启时按需加载。

外观层次与内部楼层不同。室内平面图和楼梯资料尚待补齐，本版不提供自主室内登楼。历史叙述参考[鹳雀楼景区介绍](http://sxgql.com/?about/)，对尚需核对的毁损年份不作具体复原。

探索进度和声音偏好保存在当前浏览器；不上传个人游览记录，无需账号和后台。

## 文件与维护

- `index.html`：界面与导览入口。
- `assets/experience-v2.css`、`assets/experience-v2.js`：样式、场景与交互。
- `assets/guanque-exploration.glb`：带楼层和构件分组的互动模型。
- `assets/audio/`：配乐、环境声、朗诵与讲解。
- `assets/vendor/`：Three.js 0.170.0 及必要模块。
- `tools/export-standalone.py`：从当前发布文件生成独立 HTML。

纯静态网站，无需构建工具或后端。可在仓库目录运行 `python3 -m http.server 8000`，然后访问 <http://localhost:8000/>。

生成可直接打开的独立 HTML（内嵌模型、音频和页面代码，Three.js 通过 CDN 引入）：

```sh
python3 tools/export-standalone.py
```

默认输出 `dist/guanque-tower.html`。线上版的页面、模型、声音和 Three.js 全部由本站提供，运行时无需外部 CDN。

GitHub Pages 使用 `main` 分支的 `/ (root)` 目录；推送更新后自动部署。`preview/` 为版本预览入口。
